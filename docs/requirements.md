# Ukiyo 浮世 · 需求文档

> 原图跨机互传，24 小时后不留痕迹。

## 1. 背景与目标

在微信里发原图或动态照片，一张经常超过 10MB。接收方的聊天记录里会存一份，点"保存到相册"后又多一份，存储被白白占用；发送时还可能被压缩。

Ukiyo 要做到：
- **原图**：字节不变，不压缩、不转码。
- **只存一份**：接收方直接存进系统相册，App 里不留副本。
- **跨品牌**：不同品牌的安卓手机之间可以互传，没装 App 的人用网页下载。
- **阅后即焚**：链接 24 小时后失效，服务器上的文件同时删除。
- **轻量**：APK 不超过 8MB，后端能在 2 核 2G 的服务器上运行。

## 3. 角色

| 角色 | 说明 |
|---|---|
| 管理员 | 部署服务器、发放邀请码（就是你自己） |
| 发送者 | 持有邀请码的朋友，可以上传 |

## 4. 功能需求：安卓 App

优先级：**P0** 第一期必须有，**P1** 第一期尽量做，**P2** 以后再说。

### 4.1 设置
- **F1（P0）** 首次打开时填写服务器地址和邀请码，保存在本机，之后可以在设置页修改。
- **F2（P0）** 邀请码无效时（服务器返回 401）明确提示，并引导用户去修改。

### 4.2 发送
- **F3（P0）** 从系统相册多选照片和视频。读取的必须是**原始文件**，不能拿缩略图或转码后的版本。
- **F4（P0）** 支持从系统相册或其他 App 点"分享 → Ukiyo"直接进入发送流程（`ACTION_SEND` / `ACTION_SEND_MULTIPLE`）。
- **F5（P0）** 上传时显示进度。失败时提示原因（网络问题、文件太大、邀请码无效），并能重试。
- **F6（P0）** 上传成功后显示链接，可以一键复制，也可以调起系统分享面板发到微信等 App。
- **F7（P1）** 上传过程中切到后台不中断（前台服务或 WorkManager），在通知栏显示进度。
- **F8（P1）** "我发出的"列表：显示每条链接和剩余时间，只存在本机。

### 4.3 接收
- **F9（P0）** 点击 `https://<域名>/s/<token>` 链接时，可以选择用 Ukiyo 打开（intent-filter）；也支持在 App 里粘贴链接。
- **F10（P0）** 打开后显示文件列表（文件名、大小、预览图），以及剩余时间。
- **F11（P0）** 一键全部保存到系统相册，用 MediaStore 写入，保留原始字节和原文件名。下载用的临时文件保存完立刻删除，**App 里不留副本**。
- **F12（P0）** 链接过期或不存在（服务器返回 404）时，明确提示"已销毁"。
- **F13（P1）** 下载支持断点续传（服务器已支持 Range 请求）。

### 4.4 动态照片
- **F14（P0）** 安卓动态照片（JPEG 里嵌了 MP4）按原始字节传输和保存。同品牌手机之间应该还能识别成动态照片。
- **F15（P2）** 跨品牌的动态照片格式转换，放到第二期。

## 5. 功能需求：后端

已实现的功能见 `README.md` 的 API 一节。还没做的：

- **S1（P1）** 发送者可以提前删除自己的分享：创建分享时额外返回一个 `delete_key`，用 `DELETE /api/shares/{token}` 删除。
- **S2（P1）** 磁盘保护：剩余空间低于某个阈值时拒绝新的上传，避免把磁盘写满。
- **S3（P2）** 按邀请码限流。

## 6. 非功能需求

| 项目 | 要求 |
|---|---|
| APK 体积 | release 包不超过 8MB（开启 R8 代码压缩） |
| 系统版本 | minSdk 29（Android 10）。写入相册不需要存储权限，可以直接用 MediaStore 的 `IS_PENDING`。 |
| 国产机兼容 | 不依赖 Google Play 服务（国产机普遍没有）。选图用 `PickMultipleVisualMedia`，在没有 GMS 的机型上它会自动降级成系统文件选择器，需要真机验证。 |
| 鸿蒙 | HarmonyOS 4 及以前可以装 APK；HarmonyOS NEXT（纯血鸿蒙）装不了 APK，这部分用户用网页兜底。 |
| 隐私 | 不接任何统计或埋点 SDK。注意：没有 `ACCESS_MEDIA_LOCATION` 权限时，安卓会抹掉照片里的 GPS 信息。默认接受这种行为（对分享来说反而是好事），需要真机确认除此之外字节不变。 |
| 传输 | 只走 HTTPS。邀请码放在 `Authorization` 请求头里。 |
| 服务端资源 | 常驻内存低于 50MB，上传时边收边写盘，不在内存里整体缓冲。 |

## 7. 技术选型（安卓）

| 用途 | 选择 | 说明 |
|---|---|---|
| 语言 | Kotlin | |
| UI | Jetpack Compose | 目前安卓的主流写法，也适合学 |
| 网络 | OkHttp | 上传进度和断点续传都好做 |
| JSON | `org.json` | 安卓系统自带，不需要额外依赖 |
| 图片预览 | Coil | 用来加载远程缩略图 |
| 异步 | Kotlin 协程 | |
| 本地存储 | SharedPreferences | 只存服务器地址、邀请码和发送记录 |

**不引入**：Retrofit、Hilt/Dagger、Room、RxJava。规模这么小的项目用不上，加进来只会增加学习负担和 APK 体积。

## 9. 已知限制

- 国内服务器公网带宽通常只有 3–5 Mbps，一个 10MB 的文件下载大约要 20–30 秒。
- 在微信内置浏览器里打不开下载，需要点"在浏览器打开"（网页上已经有提示）。
- 域名接入 80/443 端口需要先做 ICP 备案，一般要 1–3 周。
